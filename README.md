# Lottery-Ticket-Hypothesis

This repository presents an implementation of the Lottery Ticket Hypothesis (LTH) using PyTorch, exploring how sparse subnetworks, known as “winning tickets,” can emerge within randomly initialized neural networks. The project includes iterative magnitude pruning, sparsity analysis, dead neuron detection, weight rewinding, and performance comparison before and after pruning on datasets such as Iris and MNIST. Designed for both learning and experimentation, the repository demonstrates how efficient sparse neural networks can retain strong performance while using significantly fewer active parameters.
